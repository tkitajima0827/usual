# 有価証券損益管理システム

SBI証券の取引データ（約定履歴）をもとに、銘柄ごとに現物・信用取引を移動平均法で
原価計算し、実現損益・月末の時価評価損益を算出したうえで、MF会計インポート用の
仕訳CSV/Excelを生成する社内向けWebアプリです。事業者（テナント）は複数登録でき、
社内メンバーは事業者を切り替えて利用できます（社外ユーザーの招待機能はありません）。

## 主な機能

- **データ取込**: SBI証券「約定履歴照会」のエクスポート（.xlsx / .csv）をアップロードし、
  自動でパースします。
- **原価計算エンジン**: 現物・信用買建・信用売建をそれぞれ独立した移動平均法のロットとして
  管理し、現引・現渡（信用⇔現物の付け替え）も正しく処理します。詳細は
  `src/lib/engine/costEngine.ts` のコメントを参照してください。
- **仕訳生成**: 取引および月末評価から複式簿記の仕訳を自動生成し、
  `/journal` から MF会計インポート用の CSV / Excel をダウンロードできます。
- **月末時価評価**: 売買目的有価証券について月末単価を入力すると、帳簿価額との差額を
  有価証券評価損益として自動計上します。
- **ダッシュボード**: 指定月末の銘柄別残高・評価損益、期間を通じた月別推移グラフを表示します。
- **事業者切り替え**: 1ユーザーが複数事業者に所属可能。管理画面から事業者・会計期間・
  社内メンバーを管理できます。

## セットアップ

```bash
npm install
cp .env.example .env   # AUTH_SECRET を openssl rand -base64 32 などで生成して設定
npx prisma migrate dev
npm run db:seed              # 蛤覚合同会社 + 管理者ユーザー(初期パスワード changeme123)を作成
npm run db:seed:hamaguri     # 26.02月期の参考データ(2026年2月の実データ)を投入 (任意)
npm run dev
```

初回ログイン後、管理画面（`/admin`）からパスワードの再設定や社内メンバーの追加を行ってください。

## 開発フロー

1. `/admin` で会計期間・社内メンバー・事業者を作成する
2. `/opening-balance` で期首（または直近確定月末）の保有銘柄・株数・帳簿残高を登録する
   （前期末の残高証明書を参照）
3. `/import` で当月分の元データ（約定履歴）をアップロードする
   → 自動で原価計算・実現損益計算・仕訳作成まで実行されます
4. `/valuation` で当月末の株価を入力し、時価評価損益を計算する
5. `/journal` で仕訳を確認し、CSV/Excelをダウンロードして MF会計にインポートする
6. `/dashboard` で残高・評価損益の推移を確認する

## データモデルの要点

- `Business` = 事業者（テナント）。`Membership` でユーザーと紐づけ、ADMIN/MEMBER の権限を持つ。
- `FiscalPeriod` = 会計期間（例: 26.02月期）。
- `OpeningBalance` = 会計期間開始時点（または直近確定時点）の現物・信用買建・信用売建の
  残高。信用買建と信用売建は別々のロットとして扱う。
- `Trade` = SBI証券の元データを正規化した取引明細（現物買/売、信用新規買/売、
  信用返済買/売、現引、現渡）。
- `CostLedgerEntry` = 移動平均法による原価台帳。取引ごとの残高・実現損益のスナップショット。
- `MonthEndPrice` / `Valuation` = 月末単価と評価損益。
- `JournalEntry` = 生成された仕訳（取引起因 / 評価起因）。

## 原価計算・仕訳のロジックについて

現引・現渡は「新規建て時と全く同一の約定単価で決済される」という実際の値動きを
実データで確認したうえで実装しています（信用側では損益ゼロ、現物側の平均原価との
差額でのみ実現損益を認識）。仕訳の勘定科目（信用取引未払金・担保差入有価証券・
借入有価証券・担保差入金・差入証拠金など）も、実際にMF会計へ登録されている
仕訳データの内容を解析して再現しています。詳細は `src/lib/engine/journalRules.ts`
のコメントを参照してください。

`prisma/seed-hamaguri-202602.ts` は蛤覚合同会社の2026年2月の実データ（元データ全42件、
2026年1月末時点の現物保有、2026/2/27時点の実際の株価）を投入する参考スクリプトです。
投入後の銘柄別実現損益・評価損益は、実際の「有価証券評価損益計算」シートの数値と
完全に一致することを確認済みです。ファイル冒頭のコメントに、期首データが未取得の
信用建玉（寿スピリッツ・iFreeETF・宮地エンジニアリンググループ）に関する扱いを
明記しています。

## 今後の拡張

- MFクラウド会計APIへの仕訳の直接反映（今回はCSV/Excel出力のみ。誤って本番の会計帳簿に
  書き込むリスクを避けるため、直接連携は意図的に実装していません）
- 配当金・入出金明細の取込と仕訳反映
- 信用建玉（買建・売建）自体の時価評価
- 事業者ごとの現金科目名・補助科目名のカスタマイズ（現在は預け金の補助科目名等は
  `DEFAULT_CASH_SUB_ACCOUNT` で固定）
